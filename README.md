# PPG Lab

An Android app that reproduces the method in Sharma et al., "Heart rate and
blood pressure measurement based on photoplethysmogram signal using fast
Fourier transform", Computers and Electrical Engineering 101 (2022) 108057.

Hold a fingertip over the rear camera and flash for thirty seconds. The app
averages the red and green values of every frame, transforms both arrays, takes
the strongest frequency in the cardiac band, averages the two channels, and
runs the paper's six equations for blood pressure. Everything is stored on the
device and can be re-analysed at any time.

The paper published no code, no app and no data, so this is a from scratch
reproduction, built to the text of the paper rather than to an author's binary.

---

## Read this first

- **Not a medical device.** The heart rate is an estimate from a camera. The
  blood pressure is a model output computed from that estimate, and the paper
  never compared it with a cuff.
- **The 98 percent claim is the paper's, not this app's.** This app measures
  nothing about accuracy and does not report a figure. `docs/validation.md`
  says how to measure it yourself, and what would have to be true before
  anyone calls the result accurate.
- **Two pipelines.** The paper path is the default and is exactly what the
  paper describes. A robust path adds the preprocessing the paper leaves out
  and is labelled wherever it appears.

## Layout

```
lib/                      the Flutter app
  design/                 tokens, theme, page frame, charts
  data/                   Drift database, codec, profile
  measure/                camera channel, frame sources, capture controller
  state/                  app scope and profile controller
  ui/                     nine screens
packages/ppg_core/        the paper's maths, pure Dart, no Flutter
  lib/src/fft.dart        radix-2 FFT
  lib/src/paper.dart      Eq. (2), the band limit, Alg. 1
  lib/src/bp.dart         Eqs. (3) to (8)
  lib/src/robust.dart     opt-in preprocessing
  lib/src/quality.dart    perfusion, clipping, frame jitter
  test/fixtures/          golden data generated by the Python reference
tools/pyref/              second implementation, agreement analysis
assets/fonts/             Roboto Mono, for the worked equations only
android/app/src/main/kotlin/app/ppglab/ppg_lab/
                          CameraX capture, YUV to per frame means
docs/                     the four documents above, plus the screenshots
check.sh                  regenerate fixtures, run all tests
```

## Build

The app targets Android 15 (target SDK 35, compile SDK 36 because CameraX
1.6 requires it, minimum SDK 26). It
declares the camera and torch only; there is no `INTERNET` permission, so the
absence of network access is enforced by the operating system.

```
flutter pub get
flutter build apk
```

`check.sh` is the full verification: it regenerates the fixtures from the
Python reference, runs the core tests against them, then analyses and tests
the app.

```
chmod +x check.sh
./check.sh
```

The repository also contains `.toolchain/`, a self contained JDK 17, Android
SDK and Flutter install used to build and verify this project without root. It
is gitignored and not needed if you have your own toolchain.

---

## What the app does with your data

Nothing leaves the phone. Readings, raw signals and body parameters are stored
in a local SQLite database. There is no account, no sync, no analytics and no
crash reporting. Settings has a single button that deletes everything.
